# antislop audit 001 (2026-10-12)

Mode: after (audit of a finished project). Scope: the site (`web/`), the extension UI (`extension/src/*.html`, popup, badge, setup), the agent's user-facing strings, `README.md`, `SUBMISSION.md`, `DESIGN.md`, and comments in code Nadeye wrote. Direction: `DESIGN.md` (Nadeye design system, built on Monad's brand kit).

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW. Nothing has been changed yet.

## Findings

### HIGH

1. **R-03 Tap targets below 44px on phones.** At 375px: the section tabs are 29px tall, `.btn` buttons 31px, the search input 33px, the sort select 35px, pager buttons 36px, and the sortable column headers 13px. Fix: give tabs, buttons, inputs, the select, the pager and the header sort buttons a 44px minimum height on narrow or touch screens.
2. **R-27 Missing loading and empty states on the site.**
   - When a contract is configured, the page first paints generated example rows and only swaps in chain data when the read finishes. There is no loading state.
   - A live registry with no scanners shows "No scanners match that search." even with no search, and an empty feed shows nothing at all.
   - Fix: a loading state while the chain read runs, and separate copy for "no scanners yet", "no matches" and "no images yet".
3. **R-38 / R-36 Wrong specifics in site copy.**
   - Step 3 says verdicts go out in one transaction "of up to 100". The extension sends at most 50 (`MAX_BATCH`); 100 is the contract's limit.
   - The hero says every scanner's track record accrues to its ERC-8004 identity. That only happens for scanners that link an agent.
4. **R-02 Em dashes in shipped text.** About 20 in user-facing strings:
   - **Site:** the meta description.
   - **Extension:** the popup, options and setup pages, badge tooltips, and the model-status lines.
   - **Agent:** two error messages.
   - **Docs:** `README.md` (2), the `SUBMISSION.md` title, and the `SECURITY.md` finding headings.
   - Left alone: `NOTICE` (legal attribution) and comments in Sieve's own code.
5. **R-25 Inactive sort arrows below contrast.** The ▼ on unsorted columns is drawn at 35% opacity: 1.97:1 on night, 1.69:1 on day. Fix: raise it to at least 3:1, or show the arrow only on the active column.

### MEDIUM

6. **R-01 Gradient on the first-place podium card.** `.pod.r1` uses a `linear-gradient`, while `DESIGN.md` says "No gradients." Fix: a flat `accent-soft` fill with the brand border.
7. **R-19 Fade-in on every view switch.** `.fade` animates opacity from 0.4 to 1 over 350ms whenever a tab changes. `DESIGN.md` says state changes swap instantly, and text sits below contrast while it fades. Fix: remove the animation.

### LOW

8. **R-20 Extension setup page still says "Sieve".** The tab title reads "Sieve — Setup", the heading "Sieve — one-time model setup", and the done message "Sieve is active." People install Nadeye and are shown another product's name. Fix: name Nadeye there and keep Sieve as the credited detector. *Recommended even though it is a Quality Lock.*
9. **R-05 / R-14 "How it works" as four identical step cards.** Each card has an uppercase "STEP n" label. The four stages are real, so the sequence stays, but it reads like the template pattern. The fourth heading, "Everyone benefits", is a generic positive conclusion. Fix: a numbered list in the prose column, and a heading that says what happens ("The badge shows the count").
10. **R-16 / copy Small copy issues in the submission.**
    - "One passkey, many keys" sits above a sentence about two keys.
    - Inline bold headers are stacked through the write-up.
    - The launch post uses decorative emoji (🟣 ⬇️).
    - "Everything in the repo except the detector" leaves out the vendored ERC-8004 test copies.
11. **antislop-code Comment hygiene.**
    - Fifteen decorative `// ------ label` banner lines, in `Nadeye.sol`, the site script and `passkey.js`.
    - Three over-explained comment blocks: `AI_THRESHOLD` (5 lines), `REPUTATION_GAS` and the vote bands in `chain/config.js`.
    - Keep the three markers that show where Nadeye's code starts inside Sieve's files, as one plain line each.
    - File headers and NatSpec stay.
12. **R-31 No dial line in `DESIGN.md`.** Fix: add `Dial: ENERGY 1 / RHYTHM 2 / MOTION 1` (calm, a few deliberate breaks, hover states only), which matches what the system already specifies.
